\# RoamWise AI — Personalized Travel Itinerary Planner 🌍✈️



RoamWise AI is a modern travel planning web application that generates personalized, day-by-day travel itineraries based on user preferences, destination, budget, group size, and travel pace.



\---



\## 📌 Project Overview

\- \*\*Multi-Step Trip Planner\*\*: Destination, duration, budget tiers, travelers, pace, and interests.

\- \*\*Structured Schedules\*\*: Morning, afternoon, and evening breakdowns with estimated costs.

\- \*\*Interactive Editing\*\*: Add or remove custom activities dynamically.

\- \*\*Trip Persistence\*\*: Save itineraries to browser storage and review them in the Saved Trips dashboard.

\- \*\*Print \& PDF Export\*\*: Clean, print-optimized formatting.

\- \*\*Dual Engine\*\*: Client-side fallback generator paired with FastAPI backend endpoint (`/api/plan`).



\---



\## 🛠️ Technology Stack

\- \*\*Frontend\*\*: React 18, Vite, JavaScript, Tailwind CSS, Lucide Icons

\- \*\*Backend\*\*: Python 3.10+, FastAPI, Uvicorn, Pydantic

\- \*\*Storage\*\*: LocalStorage / Supabase PostgreSQL ready
